A two-line explanation of an everyday thing for a 10-year-old: line 1 explains rain through one vivid analogy, and line 2 honestly says what that analogy maps and what it leaves out. The program writes the two lines to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
